# IMCCalc - Queren Nalevaiko de Carvalho

Aplicativo Android desenvolvido em **Kotlin** para calcular o Índice de Massa Corporal (IMC).

## Funcionalidades

- Inserir peso (kg) e altura (m).
- Validar os valores informados.
- Calcular o IMC.
- Exibir o resultado e sua classificação em uma nova tela.
- Voltar à tela inicial para realizar outro cálculo.
- Limpar os campos de peso e altura.

## Tecnologias

- Kotlin
- Android Studio
- Android SDK 37
- XML para as interfaces

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/QuerenNalevaiko/IMCCalc.git
   ```
2. Abra o projeto no **Android Studio**.
3. Aguarde a sincronização do Gradle.
4. Selecione um emulador ou dispositivo Android.
5. Clique em **Run** para executar o aplicativo.

## Como utilizar

1. Informe o peso e a altura.
2. Clique em **Calcular**.
3. Visualize o IMC e sua classificação na tela de resultado.
4. Clique em **Voltar** para retornar à tela inicial.
5. Utilize **Limpar** para apagar os valores e realizar outro cálculo.
